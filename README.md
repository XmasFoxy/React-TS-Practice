# Gelato — магазин мороженого

Учебное SPA-приложение на React и TypeScript. В проекте будет каталог мороженого с данными в Firebase Firestore. На первом этапе настроены Vite, строгая проверка TypeScript и Tailwind CSS.

## Технологии

- React
- TypeScript
- Vite
- Tailwind CSS

TanStack Router, TanStack Query и Firebase Firestore будут добавлены в следующих этапах.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
npm install
npm run dev
```

Для проверки типов и production-сборки:

```bash
npm run typecheck
npm run build
```

Для запуска линтера:

```bash
npm run lint
```
